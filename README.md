# 🎱 로또 3D 추첨기

동행복권 사이트의 밋밋한 자동 번호 대신, 유리구 안에서 마구 날아다니는 공을 **직접 클릭해서** 6개를 고르는 3D 로또 추첨기입니다.

두 가지 버전이 있고, 화면 오른쪽 위 링크로 서로 오갈 수 있습니다.

| 버전 | 파일 | 방식 |
|---|---|---|
| 🎱 유리구 | `index.html` | 바람에 날아다니는 공을 직접 클릭해서 6개 선택 |
| 🎯 핀볼 | `pinball.html` | 공 45개가 랜덤 위치에서 쏟아져 핀에 튕기고, GOAL에 먼저 들어온 6개가 당첨 |

## 사용법

파일을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 빌드가 없습니다.

### 🎯 핀볼 버전

- **🎳 공 떨어뜨리기** : 45개의 공이 매번 랜덤한 위치와 순서로 위에서 떨어집니다.
- 핀과 범퍼에 튕기며 내려오다가 **블랙홀**에 빠지거나 바닥의 **OUT** 포켓에 들어가면 사라집니다.
- 가운데 **GOAL** 포켓에 먼저 들어온 6개가 당첨 번호입니다. 6개를 못 채우면 사라진 공을 다시 떨어뜨립니다.
- **새 판** 버튼을 누르면 핀·범퍼·블랙홀 배치가 새로 랜덤하게 만들어집니다.
- 유리구 버전과 추첨 기록을 공유합니다.

### 🎱 유리구 버전

- **💨 바람 켜기** : 바닥 노즐에서 바람이 나와 45개의 공이 유리구 안을 날아다닙니다.
- **공 클릭** : 마음에 드는 공을 클릭하면 아래 트레이로 빨려 나옵니다. 6개를 고르면 결과 창이 뜹니다.
- **🎰 자동 추첨** : 기계가 1초 간격으로 공을 하나씩 뽑습니다. 도중에 직접 클릭해도 됩니다.
- **바람 세기** : 공이 너무 빨라 클릭하기 어려우면 슬라이더로 줄이세요.
- **드래그** : 화면을 끌어서 유리구를 돌려볼 수 있습니다. 모바일 터치도 지원합니다.
- 결과 창에서 번호 복사가 가능하고, 최근 20회 추첨 기록이 브라우저에 저장됩니다.

## 기술

- [Three.js r128](https://threejs.org/) (cdnjs CDN) 으로 렌더링, 파일 하나로 구성
- 공 색상은 동행복권 실제 공 색상 구간을 따릅니다 (1~10 노랑, 11~20 파랑, 21~30 빨강, 31~40 회색, 41~45 초록)
- 중력, 바람 기둥, 소용돌이, 난류, 공끼리의 충돌을 직접 계산한 간단한 물리 시뮬레이션 (핀볼 버전은 보드 평면 2D 물리 + 핀·범퍼·캡슐 충돌)
- 효과음은 Web Audio API로 합성 (🔊 버튼으로 끌 수 있음)
